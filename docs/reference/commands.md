## `kuali connect`

Point the Connector at a specific Kuali instance and save it as the default (or as a named profile).

```
kuali connect <url> [--profile <name>]
```

**Example:**

```bash
kuali connect https://myschool.kuali.co
kuali connect --profile sandbox https://sandbox.myschool.kuali.co
```

---

## `kuali login`

Sign in via browser-based single sign-on.

```
kuali login [--no-browser]
```

`--no-browser` prints a code you paste manually instead of opening a browser tab. Useful on headless systems.
