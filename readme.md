# Kuali Connector

**Connect Kuali to your AI assistant.**

The Kuali Connector lets Claude, Copilot, Gemini, Codex, and any other MCP-compatible AI assistant work directly with your Kuali instance — pull data, build apps, move workflows, and run reports in plain English. It also works as a full-featured CLI for scripting and automation.

## 👉 Full documentation

### **<https://connector.kuali.co>**

Start there for install instructions, the AI-assistant setup guide, the prompt library, and the complete command and tool reference.

## Quick install

```bash
# macOS / Linux
curl -fsSL https://connector.kuali.co/install.sh | sh
```

```bash
# Homebrew
brew install kualico/tap/kuali
```

Windows users and everyone else: see the [install guide](https://connector.kuali.co/installation/).
